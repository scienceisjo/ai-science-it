# NET ZERO ECO-CITY

AI와과학을IT다 연구회의 고등학교 데이터 기반 탄소중립 도시 탐구 RPG입니다.
인창고 노동규 선생님의 2026.09.14 수업 시나리오를 바탕으로 구현했습니다.

**수업 웹앱:** https://scienceisjo.github.io/ai-science-it/

## 공개본

2026-09-29 city-detail 버전. NPC에게 임무를 받고 기록관 및 도시 공간을 탐구합니다.
전경, 후방 추적, 1인칭 시점을 제공하며 PC 키보드와 터치 조작을 지원합니다.
학생이 수집한 수치, 근거와 설명은 DATA PASSPORT 및 차시별 결과물로 연결됩니다.

| 차시 | 주요 학습 | 결과물 |
|---|---|---|
| 1 | CO2 배출, 에너지 구성, 국가 비교, 전력과 전체 에너지 구분 | 데이터 근거를 연결한 넷제로 필요성 설명 |
| 2 | 스톡홀름·코펜하겐·밴쿠버의 자료와 정책 비교 | 도시 정책의 적용 조건과 설계 근거 |
| 3 | 건물의 시간별 에너지 수지, 효율과 탄소 배출 구분 | 건물 개선 조건과 검증할 질문 |
| 4 | 가상 탄소 예산, 정책 조합 비교, AI 결과 검토 | 도시 설계안, 생성 프롬프트와 3D 검토 기록 |

## 저장과 연구 운영

- 공개본은 GitHub Pages의 **정적 체험판**입니다.
- 탐구 기록은 현재 기기의 브라우저에 저장됩니다. JSON으로 내보내고 가져올 수 있습니다.
- 학급별 기록 수집, 사전·사후 검사와 실험·비교집단 통제는 이 공개본에서 운영하지 않습니다.
- Claude 및 Meshy API 서버는 연결하지 않았습니다. 기본 탐구 질문과 외부 GLB 가져오기는 사용할 수 있습니다.
- 서버 미연결 기능을 사용하려고 참여 코드·비밀번호·학생 개인정보를 입력받지 않습니다.
- 로컬 파일럿 서버, 학생 기록, 검사 응답, 인증 정보, API 키, QA 기록은 게시하지 않습니다.
- localStorage 기록은 다른 주소나 기기에 자동 이전되지 않습니다. 기존 로컬 기록은 JSON으로 옮겨야 합니다.

## 데이터와 모형의 구분

OWID의 2024년까지의 수업용 스냅샷, 공식 도시 보고서와 BDG2 건물 계량 자료를 사용합니다.
각 자료의 출처·기준 연도·단위는 탐구 화면과 data/ 파일에서 확인할 수 있습니다.
태양광 곡선, 효율 감소율, 가상 도시 배출과 감축률은 명시된 교육용 가정이며 실측 성과가 아닙니다.
에너지 수지 0은 탄소중립 또는 제로에너지 건축물 인증을 자동으로 뜻하지 않습니다.

태양광 지붕, 녹지, 로봇과 Meshy 건물은 공간 탐구를 돕는 시각화입니다.
형태가 친환경적으로 보인다고 실제 감축 효과나 과학적 성능이 검증된 것은 아닙니다.
주변 주거 건물은 배경이며 출입 가능한 학습 시설과 구분됩니다.

## 자산 및 게시

- Three.js r128, GLTFLoader, GLTFExporter 및 Lucide는 vendor/의 로컬 파일을 사용합니다.
- 라이브러리 라이선스는 vendor/THREE-LICENSE.txt와 vendor/LUCIDE-LICENSE.txt에 있습니다.
- 3D 자산은 조승재가 Meshy AI로 제작·제공한 교육용 모델을 웹용으로 최적화한 것입니다.
  생성 모델 정보와 원본 해시는 assets/models/의 JSON에 있습니다.
- 기존 이야기 배경 이미지의 생성 기록은 assets/ASSET-NOTES.md에 보존되어 있습니다.
- main 브랜치 루트를 GitHub Pages로 게시합니다. 이전 버전은 Git 이력에 보존됩니다.
- 이 저장소의 공개 여부는 모든 수업 콘텐츠·3D 자산의 무제한 재배포 허락을 뜻하지 않습니다.
