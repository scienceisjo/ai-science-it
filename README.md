# AI와과학을IT다

**AI와과학을IT다 연구회**의 과학 탐구 수업 자료 저장소입니다.

## NET ZERO 2050: 사라진 도시의 설계도

고등학교 50분, 프로그램 2의 1차시를 위한 학생 자율 탐구형 웹앱입니다.

학생이 3D 도시의 탐구 지점에서 자료를 읽고, 근거를 정리하고, 다음 실험을 위한 설계 의뢰서를 남깁니다. 3D 이동 없이도 모든 탐구 자료에 접근할 수 있습니다.

### 탐구 흐름

각 탐구는 **읽기 → 정리하기 → 확인하기**로 구성됩니다. 과제와 남길 기록이 먼저 제시되며, 문장 시작 예시와 작성 상태를 확인할 수 있습니다. 기록을 확정하면 다음 탐구가 열립니다.

| 탐구 | 시간 | 남길 기록 |
|---|---|---|
| 전력·에너지 구분 | 9분 | 단위 선택, 과거 복원과 미래 설계의 공통점 |
| 실제 국가 데이터 비교 | 11분 | 예측, 수치 두 개 이상을 포함한 비교 근거 |
| 기술·정책 탐구 | 10분 | 선택 기술의 원리, 실제 정책, 효과 해석의 한계 |
| 가상 도시 진단 | 7분 | 선택 도시의 두 수치에 근거한 우선 문제 |
| 설계 의뢰 | 13분 | 의뢰서 네 항목, 자기 점검, 개별 퇴실 질문 |

기존의 교사 설명 시간을 학생이 읽고 정리하는 활동으로 전환했습니다. 교사는 순회하며 자료 해석과 근거의 타당성을 지원합니다. 서술형은 자동 채점하지 않습니다.

### 차시 연결

프로그램 1의 증거 수집 → 환경 추론 → AI 생태계 복원 → 과학적 검증 구조를 이어받습니다. 프로그램 1에 참여하지 않은 학생도 읽을 수 있는 연결 사례를 포함합니다.

이번 차시의 의뢰서는 이후 탄소 시나리오 비교, AI·Meshy 미래도시 시각화, 오류 검토·공유에 사용합니다. Meshy에 직접 연결하거나 자동 생성하는 기능은 없습니다.

### 자료의 구분

- 국가 자료: 2024년 OWID Energy Data / Ember 수업 고정본. `data-2024.csv`에 포함됩니다.
- 도시 자료: 인구 1만 명의 A·B·C 가상 도시입니다. 실제 도시에서 측정한 값이 아닙니다.
- 전력 탄소집약도는 gCO₂e/kWh, 발전의 생애주기 온실가스 기준입니다. 도시 전체 배출량이나 개인 가정의 전력 사용량과 구별합니다.
- 도시의 시설 배치와 형태는 교육용 시각화입니다. 선택 자체가 실제 탄소 감축 효과를 증명하지 않습니다.
- 정책의 지원·설치·참여 수를 절감률이나 감축량으로 환산하지 않습니다. 10%·20% 같은 실험 조건은 수업 가정입니다.

### 저장·접근성·운영

기록은 브라우저의 localStorage에 저장됩니다. 모둠별 JSON을 내보내고 가져올 수 있으며 의뢰서는 브라우저 인쇄로 출력합니다. 개인정보 대신 모둠 별칭을 사용합니다. 실시간 제출 서버, 로그인, 다기기 원격 관제는 연결하지 않았습니다.

화면의 교사 모드는 지도 자료를 여는 표시 모드이며 인증·접근 제어 기능이 아닙니다. 공용 기기는 활동 후 기록을 내보내고 해당 수업의 기록만 초기화하세요.

WebXR 지원 브라우저에서 VR 둘러보기 진입 코드를 제공합니다. 실제 VR 헤드셋은 검증하지 않았고, 답안은 PC·태블릿 화면에서 작성합니다.

### 구현

빌드가 필요 없는 정적 HTML입니다. 앱의 CSS·JavaScript는 `index.html`에 있으며 Three.js r128과 Lucide는 `vendor/`의 로컬 파일을 사용합니다. `assets/city-story.png`는 생성한 가상 도시 이야기 배경으로 과학적 설명도나 미래 예측이 아닙니다. 이미지 생성 기록은 `assets/ASSET-NOTES.md`에 있습니다.

GitHub Pages의 `main` 브랜치 루트에서 게시합니다. 저장소에는 학생 기록, 인증 정보, 테스트 답안, 로컬 서버 로그를 포함하지 않습니다.
