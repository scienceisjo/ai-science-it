차시의 마지막 질문을 다음 탐구로 연결

자료 탐구와 도시 설계가 주 활동입니다. 시민 회의는 선택 → 예상 → 추가 정보 → 비교 → 판단 재검토를 연결하는 짧은 이야기입니다. 고정된 대사와 질문은 두 집단에 동일하게 제시합니다.

입력 시간을 고려해 약 5분을 제안하지만 검증된 소요 시간은 아닙니다. 기존 정리 13분 안에서 탐구 정리 8분과 회의 5분으로 나눕니다. 4~6명 파일럿에서 읽기·입력 시간을 먼저 확인하세요. 느리면 1·2차시의 추가 실험은 생략하고 시간 배분을 조정합니다. 4차시에는 기존 단순 모형과 이 모형의 계산을 모두 중복 수행시키지 않습니다. 수업 방식·소요 시간은 집단 간 같게 고정합니다.

교사 도입 3~5분

  1. “오늘은 정책을 맞히는 게임이 아닙니다. 자료로 설명할 수 있는 선택을 합니다.”
  2. 실제 OWID·도시 자료와 수업용 가상값의 차이를 짚습니다.
  3. 최초 예상은 결과 전에 남기고, 변경한 변인의 수를 확인하게 합니다.
  4. “누가 이득을 얻고, 어떤 조건에서 결과가 달라지는가?”를 묻습니다. 특정 선택을 칭찬하지 않습니다.
  5. 마지막 설명과 한계가 수업의 산출물임을 알립니다.

주 화면 상단 ‘설계회의’, 탐구 마지막 단계, 4차시 탄소 설계에서 접근합니다. 기존 차시 기록을 마치면 회의로 이어지고, 회의가 미완료여도 맵으로 돌아갈 수 있습니다. 차시 완료와 회의 완료는 별도입니다.

계산 경계와 재현성

기존 1,000 tCO2e/년의 부문 구분을 공유하지만, 새 모형은 별도의 가정 계수로 계산합니다. 기존 모형의 감축량과 더하지 않습니다. 전력은 건물·교통 직접 연료와 분리합니다. 시간대 조정은 연간 감축으로 중복 계산하지 않습니다.

모든 결과는 정책과 조건으로 재계산할 수 있습니다. GDP·고용·요금의 인과 효과, 순현재가치, 실제 발전량, 대기오염 피해, 생물다양성, 전력 안정성을 예측하지 않습니다. “탄소를 줄이면 GDP가 반드시 떨어진다”는 결론도 도출하지 않습니다.

IPCC AR6 WGIII 도시 시스템과 수요·서비스는 관계·상충·조건을 검토하는 배경 자료입니다. 가정 계수를 실증한 출처가 아닙니다.

효과를 입증하기 전에, 무엇의 효과인지 정하기

가설:예상과 비교 결과의 불일치를 검토하는 활동이 근거 연결, 조건 통제, 분배 관점, 한계·전이 설명에 도움을 줄 수 있다. 아래 절차로 검증하며 긍정 결과를 보장하지 않습니다.

서로 다른 두 연구 질문을 섞지 않기

  • 디지털 환경 전체 vs 종이:같은 이야기·정보·변수·과제·시간을 사용합니다. 종이는 아래 회의지와 같은 계수/결과 표를 제공합니다. 차이가 생겨도 3D, 계산 피드백, 기록 방식 등의 묶음 효과이지 AI만의 효과는 아닙니다.
  • 생성형 AI의 추가 효과:두 집단 모두 같은 웹앱·회의·모형·시간을 사용하고 적응형 AI만 달리합니다. 기존 guided/comparison 운영과 연동하되, 실제 API 응답이 없는 고정 질문 모드는 AI 실험집단으로 분류하지 않습니다.

권장 연구 절차

  1. 수업 전에 연구 질문·주 지표·제외 기준·결측 처리·표본수 근거를 정하고 기록합니다. 학교 연구 절차, 동의·비동의 학생의 동등 수업 기회, 보관·삭제 기간을 확인합니다.
  2. 검사 초안을 교과 전문가에게 검토받고 고1 4~6명에게 읽기·풀이 시간을 점검합니다. 아래 A/B는 검증된 동형 검사나 표준화 도구가 아닙니다.
  3. 가능한 배정 단위와 오염 위험을 검토합니다. 학급 단위 배정이면 학급 내 유사성과 교사 차이를 분석에 반영합니다. 비무작위 배정이면 인과 효과를 단정하지 않습니다.
  4. 같은 사전 지식 검사와 사전 전이 과제를 실시합니다. A→B, B→A 순서를 균형 있게 배정할 수 있으나 난이도 동등성부터 확인합니다. 기존 연구 검사의 AB와 이 새 전이 과제 AB는 별개입니다.
  5. 같은 수업 시간·자료·기기 안내·교사 발문을 적용합니다. 도움 요청과 실제 AI 제공 여부를 별도로 기록합니다. 회의 로그 자체를 학업 성취 점수로 쓰지 않습니다.
  6. 사후에는 이야기 선택지를 되풀이하지 않는 전이 과제를 독립적으로 풉니다. 연습 결과를 본 학생에게 동일 문항을 다시 주어 기억 효과를 성취로 해석하지 않습니다.
  7. 집단과 시점을 가린 답안을 두 평가자가 독립 채점하고 예시 답안으로 기준을 조율합니다. 일치도와 불일치를 보고한 뒤 협의합니다.
  8. 사전 점수를 고려한 집단 차이·효과 크기·불확실성·결측/중도 이탈을 함께 보고합니다. 통계 방법은 설계에 맞게 사전 협의하고, 불리한 결과도 포함합니다.

자동으로 남는 자료 / 남지 않는 자료

JSON: 최초 선택·예상·근거 사본·확신, 누적 설정, 각 실험의 조건·예상·시각, 최종 조건·이유·한계·전이 설명, 모형 버전. CSV: 학생별 회의의 최초/실험/최종 행. 전체 학습 JSON과 보고서에도 회의 기록을 연결합니다.

공개 정적 페이지는 이 기기의 브라우저 저장입니다. 자동 학급 수집·클라우드 이어하기는 별도 서버 운영이 필요합니다. 연구 서버 사용 시 기존 스냅샷 저장 경로를 사용하며 확정 원기록과 기존 실험 행의 덮어쓰기를 거부합니다. 정적 JSON은 변조 방지 기록이 아닙니다. 새 12점 준거 점수를 서버가 자동 계산하거나 기존 18점 검사에 합산하지 않습니다.

이름·학번을 회의 자유서술에 적지 않도록 안내합니다. 익명 ID도 다른 명단과 연결되면 개인정보가 될 수 있습니다. 내보낸 파일은 교사가 승인한 경로로만 수집합니다.

독립 전이 과제·준거

미리 문항을 보아 검사 결과가 오염되지 않도록 A·B 과제와 상세 채점 자료는 공개 페이지에서 제공하지 않습니다. 연구 담당자가 별도 교사용 원본을 보관합니다.

평가 영역은 근거 연결, 조건·인과, 분배·상충, 한계·전이입니다. 확신 상승, 선택 변경, 낮은 탄소 값, 엔딩 종류, 클릭 수, 머문 시간에는 가산점을 주지 않습니다. 타당한 근거가 있으면 유지·수정·보류 모두 인정합니다.
